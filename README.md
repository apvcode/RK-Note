# RK Note Mod

**Version 1.3.1**

An unofficial, educational modification of the Russian school diary app **Eljur**, created through reverse engineering of its APK. The project documents and publishes only the original parts of the mod: Smali components, Java sources of the schedule system, visual resources and the hook map.

The base APK, the full decompiled code of the original app, its resources and any signing material are **not** included and never will be.

> This project is not affiliated with or endorsed by the Eljur developers. All product names and trademarks belong to their respective owners.

## Features

- Light, dark, OLED and Material themes, accent color and app icon selection
- Customizable bottom dock
- Glass effects with adjustable blur
- Current lesson and break countdown timer
- Custom bell schedules and homeroom periods
- Personal homework notes, isolated per account and per student
- Time-of-day greeting
- Redesigned splash and authorization screens
- Mark styling and a mark details dialog
- Network loss/recovery handling
- Built-in interface onboarding

## How it works

The original application was disassembled with Apktool: Dalvik bytecode is represented as Smali, resources as XML, images and fonts. The mod adds its own classes (`c7.*`, `rk.*`) and injects calls into the lifecycle and adapters of the original app — main screen, diary, authorization, splash.

Java sources of the schedule system live in [`mod/java/rk/schedule`](mod/java/rk/schedule); their Smali copies are generated by `scripts/build-schedule.sh`. The map of injection points is in [the architecture document](docs/architecture.md#injection-points).

## Repository layout

```
docs/       documentation
mod/        original mod code (Smali + Java) and resources
scripts/    build and verification scripts
tests/      host-side tests
third-party/ licenses of bundled third-party assets
```

This is a **source-only showcase repository**, not a standalone Android Studio project. It intentionally does not build on its own: a compatible, lawfully obtained base APK is required.

## Verification

Before publishing or after changes, run the local check (requires `ripgrep`):

```bash
./scripts/check-public.sh
```

It fails if APKs, keystores, keys or credential-like strings are present in the tree.
